# PDF 默认阅读

所有有本地 source.pdf 的文献使用原版式 PDF 阅读器；网页文献的阅读方式不改变。已有幻觉翻译产物按原文 SHA-256 自动匹配，未发现译文时先显示原文。阅读器不会重排、修复译文或自动调用模型。

## 数据与入口

- 正常入口 `/read/<文献 id>`；显式预览 `/read/<id>?mode=pdf`。
- 旧阅读方式 `/read/<id>?mode=previous`。已有 `mode=legacy`、`mode=reflow` 和 `source=web` 继续进入原路由。
- 原文和译文缓存副本、PDF 批注、阅读位置、历史快照及引用预览都位于 `.pdf-reading/<原文完整 SHA-256>/`。相同 PDF 的别名共享这份阅读数据。
- 正式文献库里的原 PDF、原译文、网页和重排笔记不重写。新面板显示原有笔记、论文笔记，并提供原阅读方式链接。之前的实验笔记也保留来源链接。旧笔记没有新 PDF 坐标时不强行迁移高亮。

## 译文配对

从本机 HJFY 的 Documents/*/original.pdf 与 Runs/*/translated*.pdf 读取已有产物。默认位置是 `~/Library/Application Support/HJFY`，可用 `EASYREAD_HJFY_HOME` 指定位置。

配对依据是原文的完整文件指纹，文件名与 HJFY 的 review 状态不作为质量门槛。首次加载最新的可读取产物，随后固定当前版本；新产物仅进入可选列表。用户切换译文前先保存当前编辑。不同页数的产物仍可打开，两侧独立翻页，同步开关禁用。尚无译文时，“重新查找已有译文”只扫描已有本地文件。

批注及引用沿用 `docs/pdf-dual.md` 的 v1 协议，包含文档、侧别、资产、版本、指纹、页码与 PDF 用户坐标。切换译文后旧批注保留，旧坐标不会绘制到新版本。问 AI 显式发送后调用现有聊天后端，保留已验证的侧别、页码、版本与同页上下文；聊天、图片及保存的回答存入该 PDF 的独立阅读目录。

## 默认切换与回退

旧单用户模式的 `.pdf-reading/default.json` 开关 `{"schema":1,"enabled":true}` 仅影响部分导入处理；当前 `pdf_reader.py` 的 `/read/` 路由直接选择该阅读器，设为 false 不会恢复旧默认路由。旧模式参数也不构成已验证的回退方案。新旧批注仍保留，原 `.pdf-reflow` 数据不修改。课程多用户模式使用独立入口及受保护的 PDF.js，不读取这个开关或个人阅读缓存，见 `docs/course/README.md`。

本地 PDF 导入默认不翻译、不匹配网页、不排后台任务，可立即读原文。用户显式勾选翻译时仍走原有手动操作。

## 验证范围

针对 EasyRead 的原文单侧、已有译文、多版本与不同页数、划线笔记保存恢复、引用身份、旧入口、无自动任务和文件保护验证。HJFY 的翻译质量、排版或公式内容不在本轮验收范围。

## 阅读外观与同步

顶部工具栏、说明条和两侧标题条默认隐藏。右上角按钮唤出阅读工具栏，“收起”或在非编辑区按 Esc 收起。工具栏仍提供翻页、缩放、译文版本、旧阅读方式、笔记和引用预览。

“背景”使用原来的原始、深色、黑色、雪色、棕褐五种配色，同时匹配 PDF 页面、周围背景和阅读面板。通过 PDF 渲染器原生配色调整显示，不修改 PDF 文件；彩色图片不反相。PDF 背景偏好单独保存在 `.pdf-reading/appearance.json`，首次继承现有阅读背景，不改变网页阅读偏好。

两侧页数一致时，同步翻页按实际 PDF 页序及页内位置跟随；滚轮、触摸操作会确定当前操作侧，只移动另一侧。启用同步时立即对齐当前阅读位置。单侧或不同页数时使用独立翻页。

## 与网页一致的划线操作

原文和译文选中文字后，菜单提供荧光笔、下划线及黄、绿、蓝、红四色；点颜色直接保存划线，并提供撤销，不打开笔记编辑器。“笔记”“提问”“问 AI”和复制是独立操作。点击纯划线可换笔型、换颜色、写笔记、提问或删除；点击已有笔记或问题直接打开编辑器。数字 1–4 对应四色，N/Q 对应笔记/提问。

笔型偏好与背景一起保存在 `.pdf-reading/appearance.json`，首次继承网页阅读的笔型。批注存储逻辑颜色及 `style`（marker/underline），原生绘制类型必须与笔型一致；缺少 style 的旧批注按荧光笔恢复。修改颜色、笔型或笔记内容不改变原 PDF 身份及坐标。选区点“问 AI”只添加引用，点击发送才调用模型。

## 手动幻觉翻译

唤出工具栏，点击“用幻觉翻译”或“重新翻译”，选择 HJFY 已启用的模型连接，确认生成中文 PDF 并保持原排版后启动。状态显示原生引擎进度，支持取消及失败后重新启动。同一原文不重复启动；关闭阅读页不会中断任务，重开可继续查看状态，不会自行启动新任务。

任务由独立本地监督进程执行，记录及最终产物位于 `.pdf-reading/<原文 SHA-256>/runs/<任务 id>/`。原生进程成功退出、协议 v4 发布及完成事件确认本次输出路径、PDF 可读取后才登记产物。完成后先保存当前编辑，再选定本次产物并重载；已有译文、原文件和 HJFY 历史记录不改写。

原生运行目录可用 `EASYREAD_HJFY_RUNTIME` 指定；本机已有 Codex 桥接启动路径和对应地址记录在 `.pdf-reading/hjfy.json`，只在显式启动翻译时按需启动，任务结束后清理自己创建的服务。现有服务不会被关闭；使用同一桥接的任务串行借用。远程连接须在 EasyRead 配置中具有同地址的 API 凭据；不会读取或改写 HJFY 钥匙串。

## PDF 问 AI 与笔记导出

复用网页的模型选择、流式回答、停止、对话列表和图片粘贴/上传。引用在发送前验证完整文件身份；切换译文后历史引用仍显示原版本，旧版本引用不跳到新文件。回答可保存到笔记，重开后恢复。Markdown 中每条 PDF 批注和保存回答标明侧别、实际 PDF 页码和版本，保留引文与正文；旧阅读笔记按来源附加，不迁移坐标。
