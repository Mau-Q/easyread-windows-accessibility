# PDF 原版式与双语默认阅读器

所有包含本地 `source.pdf` 的文献默认使用原版式 PDF 阅读器打开；当本地存在与原文 SHA-256 指纹匹配的中文译文 PDF 时，自动提供原文、译文与左右并排三种视图。打开阅读器时仅加载本地文件与缓存，不会在后台自动触发全文翻译或外部模型调用。

## 路由与数据目录

- **阅读入口**：默认入口为 `/read/<文献 id>`（或显式指定 `/read/<id>?mode=pdf`）；同时也兼容 `mode=reflow`（重排阅读）与 `source=web`（网页阅读）。
- **缓存目录**：原文与译文缓存副本、PDF 批注、阅读进度、历史快照及引用预览统一保存在数据目录的 `.pdf-reading/<原文 SHA-256>/` 下。

## 译文版本配对与批注保护

- 系统支持从 `EASYREAD_HJFY_HOME`（或默认翻译目录）下的 `Documents/*/original.pdf` 与 `Runs/*/translated*.pdf` 自动扫描并配对相同 SHA-256 指纹的译文产物。
- 首次加载时自动选用最新可读译文并锁定当前版本，后续新生成的译文进入版本切换下拉列表。切换译文版本前自动保存当前编辑内容。
- 批注与问答引用遵循 `docs/pdf-dual.md` 的 v1 坐标协议，包含文档、侧别、版本、SHA-256、页码与 PDF 用户坐标；切换译文版本后旧版本批注仍可在笔记列表中查看，不会错位绘制到新译文页面上。

## 阅读外观与双栏同步

- **简洁顶栏**：顶部工具栏默认自动收起以最大化阅读视野，可通过右上角按钮唤出，或按 `Esc` 收起。
- **五种主题配色**：提供原始、深色、黑色、雪色、棕褐五种配色，通过渲染层滤镜同步调整 PDF 页面与面板背景，同时保持论文中的彩色图表不反相；配色偏好独立保存在 `.pdf-reading/appearance.json`。
- **同步翻页**：当原文与译文页数一致时，开启“同步”后任意一侧滚动或翻页会自动按页序与页内比例同步另一侧视图；两侧页数不同时自动切换为独立翻页模式。

## 划线批注、问 AI 与笔记导出

- **快捷划线**：选中文本后弹出操作条，支持荧光笔与下划线两种笔型及黄、绿、蓝、红四色（快捷键 `1–4` 直接划线，`N` 添加笔记，`Q` 提问）。
- **手动触发翻译任务**：在工具栏点击“用幻觉翻译”或“重新翻译”并选择已配置的模型连接后，由独立本地监督进程在后台执行并实时反馈进度，支持中途取消或失败重试，产物生成并校验可读后自动加载。
- **PDF 问 AI 与 Markdown 导出**：复用流式问答、多会话管理与图片上传能力；引用发送前自动校验文件指纹与页序。导出的 Markdown 笔记会清晰标注每条批注与回答所属的侧别（原文/译文）、PDF 页码及引用原文。
