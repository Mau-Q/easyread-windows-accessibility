# 既有功能基线说明

本文档记录在进入多用户与无障碍课程开发前，项目在开源上游提交 `9e2feee` 基础上已集成的本地阅读器扩展基线。

## 功能涵盖范围

- **PDF 多模式阅读**：支持 PDF 原版式阅读、双语对照阅读与结构化重排阅读，提供划线批注、阅读历史、引用定位及 Markdown 导出能力。
- **arXiv 网页阅读**：支持 arXiv HTML 论文导入、章节导航、摘要与图表跳转及段落级双语翻译调度。
- **论文内问答**：支持多会话流式问答、多段原文引用、对话持久化及图片输入问答。
- **选词自动翻译与外观定制**：支持划词自动浮窗翻译、多模型 API 配置以及五种阅读主题配色、字号与版心调节。
- **桌面端应用**：集成 Tauri 桌面端壳层、应用图标、启动脚本及 npm/Cargo 依赖锁文件。
- **第三方阅读器资源**：`easyread/web/vendor/zotero/` 下内置 Zotero 阅读器与 PDF.js 运行资源，遵循各自开源许可证（详见 [PDF 重排阅读文档](pdf-reflow.md)）。

## 目录与数据隔离约定

- 系统临时文件（`.DS_Store`）、测试快照与日志、Tauri 生成 schema、依赖安装目录（`.venv`、`node_modules`）及编译产物（`target`）均通过 `.gitignore` 排除。
- 用户的本地文献库、账号数据库、`config.json` 密钥配置及 `.pdf-reading/` 运行缓存均保存在独立的数据目录中，不随源码提交。
- `pdf_reader.py` 的 `/read/` 路由默认启用原版式与双语 PDF 阅读器；多用户账号隔离模式下的权限校验与数据存储在此基线之上统一接管。
