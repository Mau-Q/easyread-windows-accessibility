## 已知边界

- `pdf_reader.py` 的阅读入口目前直接选择新 PDF 阅读器；`enabled()` 开关只参与部分导入处理。`pdf-reader.md` 所述开关恢复旧默认路由，以及部分旧模式参数回退说明，与当前实现不一致。本次保留现状，相关说明不能作为回退已验证的依据。
- 桌面壳面向本机使用，依赖本机 Python 环境及所选模型后端；不代表具备独立安装包或跨机器运行能力，详见 `desktop/README.md`。
- 手动 PDF 翻译可依赖本机 HJFY 运行环境；运行目录、配置和已有翻译产物不随源码提交。
- `.pdf-reading/default.json` 等本机运行配置不随源码提交，检出源码后的初始行为仍需单独验证。
