# 揭榜适配-胡瑞谦-视障友好适配

我选择的是 Windows 桌面端适配路线，在 EasyRead 文献管理与 AI 阅读系统上完成了 Windows 平台兼容性改造与视障友好无障碍适配。项目基于 [Edwardxlai/easyread](https://github.com/Edwardxlai/easyread) 演进开发，完整源码、自动化测试脚本与实测记录均已整理至仓库：[Mau-Q/easyread-windows-accessibility](https://github.com/Mau-Q/easyread-windows-accessibility)。

适配过程保留了原有的 Python 后端服务、原生 Web 界面和 Tauri 桌面端架构，对照课程任务书与《Windows 应用无障碍可访问性开发指南》，针对文献导入、分类检索、PDF/网页阅读、划线批注、个人笔记、阅读报告和问答全流程完成了无障碍改造。

## 核心修改点

1. **Windows 桌面端兼容与进程生命周期**：适配 Windows 下 Python 虚拟环境自动发现、桌面启动父子进程 PID 握手、外部链接原生打开、窗口退出确认以及后台进程树清理；修复了 Windows 下 `.mjs` 模块 MIME 类型导致 PDF.js 正文无法渲染的问题。
2. **控件可访问语义补齐**：为输入框、图标按钮、可编辑字段、文献列表、任务状态提示和阅读器正文 `iframe` 补齐 `aria-label`、`role` 及状态属性，使列表的 `aria-activedescendant` 读屏焦点与键盘实际选中行严格同步。
3. **全键盘操作与模态焦点管理**：补齐分类新建/重命名/删除、右键上下文菜单（`Shift+F10`）、六个设置页、模型配置卡片、删除确认框和会话管理的纯键盘操作；弹窗打开时锁定背景区域（`inert`）并限制 `Tab` 焦点循环，关闭后将焦点精确恢复至触发控件。
4. **阅读器跨区切换与正文定位**：支持通过 `F6` / `Shift+F6` 在顶部工具栏、PDF/网页正文与侧边面板（笔记、报告、问答）之间快速往返；支持选中文本后按 `Shift+F10` 唤出批注菜单，点击摘要、批注或阅读报告引用后自动将键盘焦点移入对应正文段落。
5. **系统高对比度主题与缩放适配**：适配 Windows 系统高对比度模式（`forced-colors`）下的文字、边框、选中态与焦点高亮，提升常规主题下的次要文字对比度，并修复低缩放比例下双页同屏时的逻辑页码同步问题。

## 测试环境与样本

- **操作系统与运行环境**：Windows x64（10.0.26300），Python 3.12.10，Rust/Cargo 1.100.0（MSVC），Build Tools 2022，Tauri 2.12.1，WebView2 157.0.4341.46。
- **无障碍测试工具**：NVDA 2026.3.1（中文界面，Windows OneCore 语音引擎）、Playwright 1.65.0、`axe-core` 4.14.0。
- **测试样本**：两页双栏合成测试 PDF（共 20 段，用于严格校验左栏到右栏的跨页朗读顺序）、公开 BERT 论文 PDF（N19-1423）以及 arXiv 网页论文（`2411.00640v1`）。
