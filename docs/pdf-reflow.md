# PDF 双语阅读

## 以阅读为目标的自动流程

`pdf_pipeline` 默认使用 `pdf_review_profile="reading"`：复用已有译文、保留原 SDT 正文与选区坐标，不对英文做全文逐字修订；译文只做一轮原页支持的含义检查。人名、单复数、引用格式与润色不触发修订，参考文献保持英文。检查结果绑定内容后缓存，继续任务不会再检查已经完成的同一份译文。旧的逐字多轮策略只在显式设置 `"strict"` 时使用。

普通正文保留网页排版，原文修订历史不再自动导致整段裁图。紧接图注的明显图内标签按原图显示，中文只显示题注。经原页确认的复杂区域可通过派生数据 `pdf_original_region_refs` 保留原件；已有译文中的公式可用 `display_math` 精确范围排版，字符与笔记偏移保持不变。实际渲染检查也检查未排版的公式代码。

影响含义但暂不能确定的译文保留并标记“这段译文需对照原文”，提供原 PDF 链接，不启动自动反复校对，也不阻塞其他正文。就绪表示译文/原件可阅读、映射与资源可用，不表示逐字准确。2026-10-13 已以 DMT 的 ACL 本地 PDF 跑通并接入原文献入口；原 PDF、原译文与原笔记保留，测试笔记不发布。本流程使用已安装的 Zotero worker，不安装 MinerU。

经过正式桌面验收的 DoReMi、LESS 和 Data Mixing Laws 使用 PDF 双语默认入口。文献详情显示“PDF 双语阅读”，显式入口为 `/read/<id>?source=pdf&mode=reflow`。已有网页原文仍优先进入网页阅读；选择 PDF 时使用已验收的双语模式。可随时点击“原阅读模式”（`?source=pdf&mode=legacy`）或“原 PDF”。其他候选仍显示“实验 PDF 阅读”。

DoReMi 已验证缓存绑定原文 SHA-256 `6bf62c211048c07b786a2d9146e6ffaf38ef8af744eebdbe5281cdaf827227b4`，位于数据目录 `.pdf-reflow/<sha256>/`。其他 PDF 的候选缓存位于 `.pdf-reflow/<sha256>/<paper_sha256>/`。缓存不属于文献内容，不提交 Git。`cache-proof.json` 绑定原 PDF、原 paper.json 和五个缓存文件的 SHA-256。独立的 `adoptions.json` 绑定正式桌面验收、缓存证明和完整适配/渲染资源身份；缓存存在不等于默认就绪。登记缺失、原文/译文/缓存或运行代码不匹配时回退原入口。渲染资源 URL 包含运行版本，防止桌面旧缓存混入新验收版本。打开阅读器不会自动解析、翻译或调用模型。

英文选区保留原字符坐标及跨页位置；中文使用现有译文和段落/图表映射，尚无逐词对齐。DoReMi 数学修复只对上述原文版本生效。

新划线通过现有 `/ops` 保存进 reader.json；`language` 指明语言，`reflow` 保存来源指纹、选择范围和原 PDF 注释位置。旧笔记只读适配；引用与前后文能唯一匹配才定位，无法确定的位置保留原笔记并提供原阅读入口。跨段英文划线在旧阅读模式可能无法显示完整高亮，实验模式的原 PDF 定位仍使用保存的多页坐标。原目录 DoReMi 在接入前没有笔记；独立样例中的测试笔记不迁入正式文献库。

阅读器现可编辑笔记正文、修改划线颜色和删除笔记（第二次点击确认，服务保留删除标记）。删除和编辑只在用户操作时产生。中文显示与 PDF 批注同步恢复。外部笔记更新在页面可见且没有待保存操作时轮询同步。

阅读进度沿用 `reader.progress.block/ratio/at`，并保存与 PDF 指纹绑定的页码和阅读模式。重开恢复原段落或原 PDF 页。旧模式写入新进度时清除过时的重排位置。进度保存不会重新装载批注。

网页与实验 PDF 阅读均保存段落在视口中的 `offset`，重开优先按段落和偏移恢复，兼容旧进度记录。网页当前段落只取可见的内容节点，收起的历史译表不参与判断。实验 PDF 的选区回原 PDF、笔记定位和引用定位保存返回位置，可点击“返回阅读位置”或在正文按 Alt+左箭头返回。

实验 PDF 复用网页阅读的配色偏好、KaTeX 和安全 Markdown 渲染。AI 回答显示公式、表格和代码，可以保存成 reader.json 中可编辑删除的正文笔记；保存身份绑定对话和消息，重复保存更新同一笔记。测试采用固定回答，不验证模型答案质量。原文结构校对仍使用独立的源页证据流程。

操作发送前写入 localStorage，每个操作独立键，键包含文献 ID 与 PDF 指纹。重开自动补存，服务确认后移除；失败显示重试按钮，较新笔记导致的冲突保留待写记录且明确报错；服务重启后的 token 失效会重新读取并重试。存储不可用时提示仅在当前页并阻止无提示关闭。该恢复范围是同一浏览器配置和服务 origin；清空浏览器数据或换浏览器不能恢复队列。

## 通用候选准备

```sh
python -m easyread.reflow_prepare --workspace /absolute/library/id \
  --worker-root /absolute/document-worker --out /absolute/candidate
```

需要已安装依赖和已构建资源的上游 worker 源码，版本须匹配文末锁定提交。准备流程在文献目录外运行，复制 PDF 输入，校验前后文献文件哈希；不修改 PDF、已有译文和笔记。先做唯一、顺序一致的正文匹配，列表编号与中间脚注仅影响匹配，不改 SDT。不能确认的映射留在 `full-mapping.json.issues`。表格本体按原件显示；题注对应与重建单元格分开，题注匹配不证明原表显示质量。DoReMi 字体、重音与固定矩阵节点修复严格绑定该 PDF，其他 PDF 不应用。

## 与网页阅读一致的内容规则

正文复用已有中文，原图表不重画、不重译。表格默认显示原件与已有中文题注；历史译表在“对照已有译表”中默认收起，原有单元格文字与选区偏移保持保留。原图表和原公式支持放大、缩放、滚动查看。

已核对的派生映射可以携带 `source_splits` 和 `source_segments`，在显示层把误并入正文的脚注拆开。拆分逐字符覆盖原 SDT 节点，文字不变，字符偏移仍映射回原索引与 PDF 坐标。唯一匹配的被排除脚注或标题可在显示层恢复。对提取后公式被展平的算法，`display_source_crop` 直接渲染指定源节点在原 PDF 中的区域；原文已有问题通过 `source_warning` 说明，不补写符号。以上处理不修改 SDT pack、PDF 或存储译文。

这些能力仅应用于经过原页、字符位置及浏览器核对的映射。生成候选、映射全部覆盖和单篇交互通过，都不会自动将 `default_ready` 改为真；默认启用还需要完整阅读与目标桌面运行环境验收。

`--ai` 使用已有翻译引擎对最多八个疑难映射提供语义校对建议；保留输入、原始回答、合法与非法建议。引用节点须存在，但合法建议仍标记为待原文核对，不直接改译文、结构或质量状态。`--install-preview` 可安装候选供实验入口查看，不改变默认路由。预览不代表公式、阅读顺序和全部译文已经通过验收。新 worker 自动安装、更多 PDF 的结构校对和默认启用仍需逐篇验证。

“问 AI”先核验来源和原段落，展示实际组装的引用上下文，点击“发送”才使用现有模型接口。对话沿用 chat.json 和原有线程，不另建模型服务。问答保存验证使用独立文献库及固定回答替身；结构与映射校对可按用户授权调用真实模型，并保存原始输入、页图身份与回答，不能将其说成未调用模型的测试。
